Tooling for Figma Plugin and Widget development.

## Requirements

The latest release of `figmadev` requires Dart SDK `3.12.0` or later.

## Installation

`figmadev` is not meant to be used as a dependency. Instead, it should be
["activated"](https://dart.dev/tools/pub/cmd/pub-global#activating-a-package).

```console
$ dart pub global activate figmadev
```

Learn more about activating and using packages [here](https://dart.dev/tools/pub/cmd/pub-global).

## 0.1.1

- Rolled the Luminous Symbols font from `v38` to `v42`.
  - This update introduces 3 new icons: `device_swoosh_spark`, `partner`, `vibe_code_app`.
  - The font now supports the [fill (`FILL`)](https://fonts.google.com/knowledge/glossary/fill_axis) axis in addition to [weight (`wght`)](https://fonts.google.com/knowledge/glossary/weight_axis) and [optical size (`opsz`)](https://fonts.google.com/knowledge/glossary/optical_size_axis) axes.

- Updated internal generation script for new font file name.
  - Generated subsets now include the `FILL` axis.

# Google Symbols

This package is published strictly for educational, scientific and research purposes only.

## Discontinued

This project has been discontinued, and will not receive further updates.

Please migrate to the [`icongen`](https://pub.dev/packages/icongen) package, which utilizes HarfBuzz to strip unused glyph data from TTF/OTF/WOFF2 font files, and generates corresponding Dart source files containing static `IconData` definitions for Flutter applications.
